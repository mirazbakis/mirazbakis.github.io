1

Get ready

  • iOS 27 or later, with Developer Mode onSettings › Privacy & Security › Developer Mode.
  • LocalDevVPNFree on the App Store. It lets the iPhone connect to itself. Open it once after installing.
  • An Apple IDA free one works. Apps then last 7 days, and AltLoad reminds you to refresh.
  • Wi-FiOnly for pairing, once.
2

Install AltLoad

Download AltLoad.ipa
  1. Sideload the IPA once with any signing tool you already use.
  2. If iOS says the developer isn't trusted: Settings › General › VPN & Device Management, then trust your Apple ID.
  3. In AltLoad, Tools › Pair, then tap Pair with AltLoad in Developer Mode settings and enter the code.

Older versions are on the releases page.

4

Good to know

Sign-in fails. What now?

Since 12 October 2026 Apple turns down sign-in data from many public anisette servers. Leave Settings › Anisette on Automatic so AltLoad tries the ones that still work. If it keeps failing, tap Reset Anisette Data and try again a few minutes later. Settings › Apple ID › Sign In checks your account without installing anything.

SideStore's repository is down.

AltLoad tries SideStore's source, its mirror, its GitHub releases and a known-good build, then its own saved copy. If none of them answer, pick a SideStore IPA you already have with Install IPA from Files.

What are the nightlies?

The newest SideStore and LiveContainer builds, straight from each project's GitHub. They install over the regular build and can be broken; switch back to Stable any time.

Does AltLoad see my password?

It's sent only to Apple. If you choose Remember password, it stays in this iPhone's Keychain and never syncs. There's no analytics or tracking.

It can't connect to the iPhone.

Check that LocalDevVPN is connected, Developer Mode is on, and this iPhone is paired in Tools › Pair. If it still fails, pair again.
